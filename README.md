## 📖 Sobre o jogo

**A Última Luz** é um projeto de jogo desenvolvido em Python, com foco em sobrevivência, narrativa e exploração em um mundo marcado pelo medo e pela incerteza.

O jogador acompanha Gabriel e outros sobreviventes que tentam permanecer vivos em meio a acontecimentos misteriosos, criaturas perigosas e segredos relacionados ao enigmático **Projeto Aurora**.

Em um cenário onde os recursos são limitados e cada noite representa uma nova ameaça, as decisões dos personagens podem determinar quem conseguirá sobreviver.

## 📚 A história

Após uma sequência de acontecimentos inexplicáveis, pequenos grupos de sobreviventes passam a procurar abrigo em locais isolados.

Gabriel, um dos personagens centrais da história, encontra pessoas que lutam para manter a esperança enquanto enfrentam perigos cada vez maiores.

Entre ruínas, cabanas improvisadas, noites intermináveis e registros de um projeto secreto, uma pergunta permanece:

**O que realmente aconteceu com o Projeto Aurora?**

A resposta pode mudar tudo.

## 🎮 Características do projeto

- 🌲 **Exploração:** descoberta de ambientes abandonados e locais misteriosos.
- 🏚️ **Sobrevivência:** busca por abrigo e recursos para continuar vivo.
- 🌙 **Sistema de noites:** acontecimentos e ameaças que evoluem com o passar do tempo.
- 👥 **Personagens:** Gabriel, Rafael, Lívia, Miguel, Helena e Daniel.
- 📜 **Narrativa:** diálogos, acontecimentos e documentos que revelam partes da história.
- 🧬 **Mistério:** investigação dos registros relacionados ao Projeto Aurora.
- 🎵 **Áudio:** recursos sonoros para ajudar a construir a atmosfera do jogo.

*As funcionalidades descritas representam os elementos planejados ou presentes no projeto; os sistemas ainda em desenvolvimento serão implementados gradualmente.*

## 💻 Como executar

### 1. Instale o Python

Baixe uma versão compatível com o projeto pelo site oficial:

https://www.python.org/downloads/

### 2. Clone o repositório

```bash
git clone https://github.com/FMed eiros-set/ultima_luz.git
```

### 3. Entre na pasta do projeto

```bash
cd ultima_luz
```

### 4. Instale o Pygame

```bash
python -m pip install pygame
```

### 5. Execute o jogo

O arquivo principal atual chama-se `last_light.py`. Se ele estiver dentro da pasta `ultima luz`, entre nessa pasta antes de executar:

```bash
python "ultima luz/last_light.py"
```

> **Observação:** ajuste o comando de execução caso a estrutura de pastas seja alterada. Se o jogo utilizar outras bibliotecas, elas também precisarão ser instaladas.
